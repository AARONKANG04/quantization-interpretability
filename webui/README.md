# qi-webui

A small local web app for reading the raw lm-eval traces of every evaluated condition (bf16, NVFP4, FP8, fp32, layers kept in bf16, mixed precision) side by side, with per-item flips against a reference condition: GSM8K chain-of-thought generations, MMLU per-choice log-likelihoods, and any other lm-eval task found on disk, plus a token view that colours held-out text by per-token KL(bf16 || quantized) from the phase 1 token dumps. It only reads data, discovers conditions at request time (Refresh data in the ⋯ menu picks up new files), has no build step and needs no network once the Gemma 3 tokenizer is in the Hugging Face cache (the first token view downloads it with `HF_TOKEN` from the repo-root `.env`; without it the token view shows token ids). Run it with `cd webui && uv run server.py` and open http://127.0.0.1:8765. Flags: `--raw-dir` (lm-eval output root laid out as `<condition>/<task>/<model_dir>/samples_*.jsonl`, default `~/qi_archive/boxA/lm_eval_raw`), `--dump-dir` (token dump parquets, default `../results/phase1/token_dump`), `--results-dir` (default `../results`, a fallback source of headline accuracies), `--port` (default 8765) and `--host` (default 127.0.0.1). Keys: j/k or the arrow keys move between items, / opens the search, Esc closes popovers, and left/right page through long token documents.
